# Restaurar downloader.py

El archivo `downloader.py` quedó truncado por error al subir la v1.1.0.

## Cómo arreglarlo

1. Descarga el zip completo de la v1.1.0 (o el `downloader.py` completo desde el workspace).
2. Sustituye `downloader.py` en el repo.

```bash
git clone https://github.com/Doriogamer/DownloaderMD.git
cd DownloaderMD
# Copia el downloader.py completo aquí
git add downloader.py
git commit -m "v1.1.0: restaurar downloader.py completo"
git push
```

Los demás archivos de la v1.1.0 (main.py, requirements, setup, README, CHANGELOG) ya están correctos en main.
